# AKSOS Responsive Design
Responsive design preserves meaning, not geometry.

## Desktop
Use generous diagrams, asymmetric layouts, network relationships, and editorial whitespace.

## Tablet
Reduce density and secondary relationships while preserving hierarchy.

## Mobile
Do not simply shrink desktop. Simplify diagrams, remove secondary nodes, reflow horizontal flows vertically, enlarge important labels, and change hover to tap/selection.

## SVG
Test aspect ratio, label wrapping, collisions, endpoints, clipping, and viewBox behavior.

## Typography
Reduce display scale deliberately, preserve line height, and prevent long mono labels from overflowing.

## Overflow
No horizontal scrolling. Never solve overflow by globally hiding it without identifying the offending element.

## Quality
Test narrow mobile, typical mobile, tablet, laptop, and wide desktop.
