# AKSOS Design System
You are the visual design authority for AKSOS.

Inspect `lib/tokens.ts`, `app/globals.css`, existing typography, assets, header/footer, and diagram styling before changing them.

## Visual character
Editorial restraint, infrastructure, intelligence, precision, human agency, African context.

## Typography
SERIF = conceptual/strategic statements.
SANS = navigation/explanation/interface.
MONO = system labels/metadata/technical states.
Do not use huge headings everywhere or mono for body copy.

## Color
Use the existing warm paper / ink / rust / green system. Color communicates state, priority, activation, category. Avoid gradients and neon.

## Composition
Vary statement-first, asymmetric editorial, diagram-first, full-width system, centered architecture, and operator-centered layouts.

## UI states
Every interactive element needs default, hover, focus-visible, active/selected, and disabled states where relevant.

## Cards
Cards are not the default container. Use them only when grouping information improves comprehension.

## Quality test
Ask: Does this feel like AKSOS? Is hierarchy obvious? Is the visual doing information work? Did this become generic SaaS? If yes, redesign.
