# AKSOS UX Architecture
Design what the visitor should understand, not merely where components sit.

## Core model
Visitor = hero. AKSOS = ally. ATIS = intelligence/perspective. RITA = investigation/relationships. Batana = human/action.

## Journey
SEE → CONNECT → UNDERSTAND → ACT → BUILD
fragmentation → relationships → context → intelligence → agency → participation.

## Section test
For every section define:
1. visitor's starting knowledge
2. new idea to understand
3. evidence/visual
4. interaction
5. reason the next section follows

## Information hierarchy
PRIMARY = one memorable idea.
SECONDARY = supporting explanation.
TERTIARY = metadata.
VISUAL = mechanism that makes the idea understandable.

## Interaction
Only add interaction when it reveals meaningful information.

## CTA
Ask for action after understanding, not before.

## Reject
Repeated card grids, feature lists without context, duplicated value propositions, decorative interactions, and product-first storytelling that sidelines the operator.
