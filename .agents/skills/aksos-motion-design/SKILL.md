# AKSOS Motion Design
Motion is explanatory.

## Core grammar
SIGNAL → CONNECTION → CONTEXT → INTERPRETATION → CONSEQUENCE

## Before animating
Define starting state, ending state, what changed, why it matters, and what remains visible.

## Preferred motion
Signal entry, relationship activation, path tracing, progressive investigation, context accumulation, network growth, meaningful state transitions.

## Avoid
Universal fade-up, bounce, constant floating, excessive parallax, gratuitous rotation, and large springy scaling.

## Scroll
Establish a readable initial state, then progress through meaningful states. Do not force the user to wait before content becomes readable.

## Hover/focus
Hover and focus can emphasize nodes, paths, or metadata. Focus must provide equivalent functionality.

## Reduced motion
Honor `prefers-reduced-motion`: remove large transforms and looping decoration while keeping all information visible.

## Baseline
Never hide essential content behind motion.
